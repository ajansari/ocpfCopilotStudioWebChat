Launcher button

The launcher is the floating button in the corner that opens and closes the chat.

All five styles explained
full
Icon + full label. "Close chat" while open. Default.
compact
Icon + short label. "Close" while open.
icon
Round button, icon only. An X while open.
fulltext
Full label only, no icon.
compacttext
Short label only, no icon.

Used by the full and fulltext styles.

Chat window layout

Where the chat window appears when the launcher is pressed: floating in the corner, docked to the right edge like Copilot in Edge or Office, or covering the browser window.

A share of the browser window (100%) or pixels (900). Anything smaller than the window is centred over a dimmed page.

Optional features

These only show or hide controls in the widget. The agent must support them too: in Copilot Studio open the agent, go to Settings > Generative AI, turn on File uploads and/or Collect user reactions to agent messages, then publish the agent again.

Shows a paperclip in the message box so visitors can attach files (up to 15 MB each). Hide it when the agent does not accept files.

Thumbs up / thumbs down under agent replies, with an optional comment box. auto shows them only on replies the agent marks as accepting feedback, always turns them on for every reply, never turns them off.

Try with your own agent

Paste the Direct Line secrets of your own Copilot Studio agent to chat with it here instead of the default agent. Leave both blank to use the agent from config.js.

Reminder: this works only for agents that run without authentication. The widget talks to Direct Line with a secret alone, so an agent that requires users to sign in will not respond here.

Classic experience agents only (as of October 8, 2026). Direct Line is currently offered for classic experience agents (standard harness). A new experience agent (GitHub Copilot harness) accepts the secret and shows Online, but sends no greeting and no replies, because Microsoft lists the Direct Line channel as not yet available for that harness. Use the iframe embed for those agents until Direct Line support arrives.

  1. In Copilot Studio open your agent and go to Settings > Security.
  2. Open Authentication and set it to No authentication. Save.
  3. Open Web channel security and copy Secret 1, and optionally Secret 2, into the fields below.
  4. Require secured access on that page is recommended but optional: the widget always sends a secret, so it works either way. On, the agent refuses Direct Line callers that bring no secret.
  5. Save, publish the agent again, then press Try It here.

Secret 1. Used first to request a Direct Line token for the conversation.

Secret 2. Only tried if the primary secret is rejected, so you can rotate one secret without downtime.

Secrets you paste here stay in this browser tab's session storage and are never written to a file. Anyone who has a secret can talk to the agent, so use a test agent and regenerate the secret in Copilot Studio when you are done.
